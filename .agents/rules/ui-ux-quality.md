# UI/UX Quality Rules

- Prioritize usability, accessibility, responsiveness, and visual consistency.
- Design mobile-first.
- Use semantic HTML.
- Maintain sufficient color contrast.
- Provide visible hover, focus, active, disabled, loading, and error states.
- Make interactive elements obvious and easy to use.
- Avoid overcrowded layouts.
- Use consistent spacing and typography.
- Ensure forms have clear labels and validation feedback.
- Ensure navigation works correctly on mobile.
- Test the page at mobile, tablet, and desktop widths.
- After major UI changes, inspect the page in the browser before considering the task complete.
